2. 5-Minute Quickstart

  1. Fund CometAPI.com: Create an account and purchase credits at CometAPI.com (10% bonus) ↗.
  2. Generate a Gateway API Key: Sign in with Whop, generate a cia_live_... key in the API Vault (see /docs/keys for rotation & scopes), and encrypt/sync your CometAPI key.
  3. Update Base URL: Point your OpenAI SDK client to https://api.costimplodeai.com/v1.

Python (OpenAI SDK)

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.costimplodeai.com/v1",
    api_key=os.environ["COSTIMPLODE_API_KEY"],
    default_headers={"x-byok-cometapi-key": os.environ["COMETAPI_API_KEY"]}
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Analyze portfolio risk under stress"}]
)
print(response.choices[0].message.content)

Node.js / TypeScript

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.costimplodeai.com/v1",
  apiKey: process.env.COSTIMPLODE_API_KEY,
  defaultHeaders: { "x-byok-cometapi-key": process.env.COMETAPI_API_KEY || "" }

const completion = await client.chat.completions.create({
  model: "auto",
  messages: [{ role: "user", content: "Optimize microservice latency." }]
});
console.log(completion.choices[0].message.content);

3. Cryptographic Safeguards & Whop Auth

🔐 Client PBKDF2 + AES-GCM-256

BYOK keys are validated, fingerprinted with SHA-256, auto-masked on blur, and encrypted in the browser with 100,000 PBKDF2 iterations + unique 96-bit IVs before vault sync.

🪪 Whop OAuth 2.1 + Checkout

Authentication uses PKCE-protected Whop OAuth 2.1 (GET /api/auth/whop/url) and paid subscriptions link directly to Whop Checkout pages (GET /api/billing/whop-plans).

Zero Prompt Logging: Prompts and completions never touch persistent disk, logging pipelines, or training sets. Review full details in our Compliance Whitepaper and Key Lifecycle Guide.

Gateway Key Lifecycle & Telemetry

  • GET /api/v1/keys: List active gateway tokens with masked previews and live RPM.
  • POST /api/v1/keys: Generate a scoped key (cia_live_... or cia_test_...).
  • POST /api/v1/keys/rotate: Zero-downtime rotation preserving limits and spend caps.
  • GET /api/v1/keys/usage: Real-time RPM and cumulative spend metrics.
  • DELETE /api/v1/keys: Immediate token revocation.

CometAPI Vault Endpoints

  • POST /api/v1/vault/test-connection: Validates CometAPI key syntax, SHA-256 fingerprint, and live model list reachability.
  • POST /api/v1/vault/sync: Stores PBKDF2 + AES-GCM-256 ciphertext envelope only.
